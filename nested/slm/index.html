A language model baked into another language model

The guest (1-layer char LM, TinyStories) is compiled into a single 96-wide host transformer: host lives in residual dims 0–63, guest in 64–95, one forward pass computes both. Compare against the guest run on its own, and against a same-size host that was trained to imitate the guest (mode embedding). Everything below runs live in your browser.
