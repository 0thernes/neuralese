# ROADMAP v14.1 – v14.9

Every release must meet a falsifiable acceptance criterion. Each one gets a pre-registration (hash pinned in tests) before its harness runs on real data, and failures go into that release's CLAIMS section. The baseline for every claim is v14.0 (TinyStories-8M, docs/NEURON_LENS_METHOD.md).

| ver | theme | deliverable | falsifiable acceptance criterion (fails ⇒ reported as failed) |
|---|---|---|---|
| **14.1** | more models | Fit R/S/mid lenses for distilgpt2 (6L, d=768) and GPT-2 small (12L), plus a DB and model picker in NEURON LENS | Test A median r for R.out beats the logit lens at ≥ 2/3 of non-final layers for each model, with the mismatched-null pass rate ≤ 2%. Split-half cosine ≥ 0.9 at every layer, or the fit size is doubled until it is |
| **14.2** | SAE comparison | Read SAE decoder directions (the in-app SAE, plus public GPT-2 SAEs) through the lenses; compare neuron vs SAE-feature legibility | Pre-registered: an SAE feature's out·R top-10 predicts its steering effect (Test A protocol) at a pass rate ≥ the neuron pass rate at the same layer. Reported either way |
| **14.3** | circuit tracing | Lens-space attribution graphs: edges = R-lens-projected writes × S-lens-projected reads between neurons/heads; compare with ACDC / path patching (RESEARCH tab) | On IOI and induction prompts, the top-20 lens edges recover ≥ 50% of ACDC-kept edges (AUROC > 0.7 against path-patching ground truth) |
| **14.4** | auto-labeling | Labels per neuron/head from its reads + contexts, by an on-device model or an optional API with a key the user supplies; labels carry confidences | Blind check: held-out raters (or a scripted simulator) predict the top-firing token from the label better than from a shuffled label (paired test, p < 0.01). Calibration: a confidence bin's accuracy is within ±0.1 of its stated confidence |
| **14.5** | cross-model matching | Match neurons/heads across TinyStories-1M/3M/8M/33M and GPT-2 by lens reads (Hungarian on read-overlap) | Matched pairs share steering effects (Test A Δ-logprob correlation across models) above the τ99 of random pairs, for ≥ 30% of matches |
| **14.6** | Tsotchke hooks | Expose lens reads to the TSOTCHKE group (types/Taylor tools): neuron-lens directions as typed objects; Taylor expansion error of the RelP linearisation | Measured: second-order Taylor residual ‖h(x+εv) − h − εJv‖ / ε² is reported per layer. The claim "RelP-linear is first-order accurate" fails if the ratio of the first-order error to the RelP error is < 1 at any layer |
| **14.7** | **nested-model experiments (slot reserved)** | Integration of the separate `neuralese-nested` workstream (prototyped outside this repo): lenses for models nested or embedded inside the host model, with their own NEURON LENS view | Its criteria are set by that workstream's pre-registration before it merges. Minimum gate: all v14 tests pass, and the nested model's lens passes Test A at ≥ 1 layer above the null, or the failure is reported |
| **14.8** | **nested-model × lens cross-analysis (slot reserved)** | Compare host-model lens reads with nested-model reads (does the host "see" the nested computation?) | Pre-registered in 14.7. Placeholder criterion: lens-read overlap between host and nested directions exceeds the shuffled-direction τ99 |
| **14.9** | full in-browser fit + publication | WebGPU fit of all lenses at the authors' scale (1000 × 128) in the browser; a paper-style report comparing TinyStories results with the neuron-lens Qwen3-8B/Gemma findings | A browser fit reproduces the shipped lens with cosine ≥ 0.99 per block. The report includes every failed prediction from 14.0–14.8 |

Rules carried over from v14.0: one batched commit per release, no new push triggers, no deleted branches, a hash-pinned pre-registration before data, honest CLAIMS with failures, and credit to neuron-lens and the upstream methods as prior art (original code only).
