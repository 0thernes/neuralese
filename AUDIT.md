# NEURALESE v7: audit

Scope: the whole app at v6 (gh-pages `b93570f`, main `853f544`), plus the v7 changes. Each finding lists its severity, what was found, and its status. Severity scale: **High** means wrong results or a security exposure. **Medium** means a real user-facing defect. **Low** means quality or maintainability. **Info** means a measurement with no defect.

| # | Area | Severity | Finding | Status |
|---|---|---|---|---|
| 1 | Numerical correctness | Info | Forward logits, logit lens, DLA, patching, SVD, gradients (loss, per-matrix norms, input grads) and ROME are checked against PyTorch/HF references (`ref.py`). These remain green in v7. The new statistics are checked against scipy/statsmodels: Holm and BH match to 1e-12; permutation p-values are within Monte-Carlo error of scipy's exact/20 000-resample values; Cohen d/d_z match to 1e-9. | Verified (test/research.test.mjs) |
| 2 | Undo exactness | **High** | DRILL's finite-difference and ablation measurements perturbed weights in place and restored them by add/subtract. In float32 this left 11 of 4 096 weights off by 1 ulp, so "diff orig cur" showed a residual after undo. | **Fixed**: restore by scatter of the saved values (`scatterSet` in a `finally`). New test/exact.test.mjs checks that edit → undo → redo is bitwise identical (Uint32 compare) for every edit kind, and that inspect/lossSlice/HVP leave the weights bitwise unchanged. |
| 3 | Test suite | Info | Full suite in one go: **59/59 pass** in about 102 s (`npm test`). | Verified |
| 4 | Memory leaks | Info | Ran a 500-token generation, then cycled all 46 tabs 8 times with forced GC between. JS heap went 14.9 → 14.8 → 14.8 MB, DOM listeners 438 → 452 → 452 (stable after the first visit renders lazy views), WebGL geometries 28 → 28 → 28, textures 0. | No leak found (smoke-v7 `memory`) |
| 5 | Listener / WebGL disposal | Low | Delegated handlers are installed once per element; 3D mode switches reuse or dispose meshes, so geometry counts stay flat across mode cycles. The v7 a11y MutationObserver is debounced and there is only one. | Verified by #4 |
| 6 | UI jank | **Medium** | Research computations ran synchronously. The worst long task was **19.4 s**. | **Fixed (chunked)**: stats yields per document, ACDC per node, probes per 2 documents, eval per document/fact/generation, all with progress bars. The worst long task of a built-in tool is now about 1.1 s (probe training per layer). **Open**: no Web Worker. Moving the forward pass off-thread would need a 33 MB weight copy per edit state plus edit-state syncing; chunking was chosen instead. Notebook cells run synchronously by design (the example cell takes about 4.5 s). |
| 7 | Accessibility | **Medium** | axe-core WCAG 2 A/AA across every tab found: unlabelled inputs (33 tabs) and selects (23 tabs) (critical); splitter separator missing aria-valuenow (critical); `.lnav` declared as a tablist without tabs (critical); breadcrumb `div` with aria-label (serious); scroll regions not keyboard-focusable (serious). | **Fixed**: auto-naming from the adjacent `<label>`/placeholder/row header, kept current by a MutationObserver for dynamic lists; explicit labels on the head grid and program rows; splitter gets aria-valuemin/max/now; toolbar role; `<nav>` breadcrumb; tabindex on scroll regions. Re-audit: **0 violations** (`node tools/a11y.mjs`). Open: canvases have text titles and CSV export but no data-table alternative. |
| 8 | Narrow / mobile layout | Low | At 390 px there is no horizontal overflow (scrollWidth = 390) and the tabs stay reachable. | Verified (screenshot neuralese-v7-live-narrow.png). Open: the 3D view is cramped on phones. |
| 9 | Network failures | **Medium** | Weight and tokenizer fetches had no retry; any transient error left a dead loader. | **Fixed**: 4 attempts with exponential backoff (0.5/1/2 s); fail-fast on 4xx other than 408/429; short-read detection for Range responses; retry status shown in the loader; a Retry button on final failure; progress bar has role=progressbar. `tools/netfail.mjs` injects a 503 and a connection reset and the app recovers; with HF blocked, it shows the error and the retry button. |
| 10 | CSP / security | **Medium** | There was no CSP, three.js was loaded from a CDN, and there was an inline `onclick`. | **Fixed**: meta CSP `default-src 'self'`; scripts limited to self plus the SHA-256 of the inline import map; `connect-src` limited to huggingface.co, *.huggingface.co and *.hf.co; object-src none; base-uri self; form-action none; `no-referrer`. The inline handler was removed. smoke-v7 records **0 CSP violations**. **Open, by design**: `'unsafe-eval'` (needed by NOTEBOOK's `new Function`) and `style-src 'unsafe-inline'` (inline style attributes). GitHub Pages cannot send headers, so `frame-ancestors`/HSTS are unavailable. User text is escaped before reaching innerHTML; uploaded datasets and notebooks never leave the browser. |
| 11 | Dependency pinning | **Medium** | three@0.160.0 was loaded from jsDelivr without SRI. | **Fixed**: vendored `three.module.min.js` and `OrbitControls.js` from the npm tarball (tarball integrity sha512-DLU8lc0z…uDhng== verified; file sha256 3e690ac7… and 5a44a9e8…). The app has no other runtime dependencies. puppeteer-core and eslint are dev-only. |
| 12 | Docs accuracy / honest claims | Low | The README test counts were stale (it said 32/52), the Bible said keys "1–7", and the docs header said "v5". | **Fixed**: the README states 59 tests and lists the v7 tools; ACDC is labelled node-level everywhere; a safety and ethics section was added (README and Bible). WebGPU claims stay honest: on software adapters it is slower than CPU. |
| 13 | Lint / format | Low | eslint 9 with a correctness rule set found 1 error (`no-fallthrough` after `process.exit` in cli.mjs) and 65 unused-variable warnings. | **Fixed** the error. **Open**: 65 cosmetic unused-variable warnings, and no auto-formatter is enforced (the code uses a dense one-line style on purpose). `npm run lint`. |
| 14 | Code structure | Low | The core math is DOM-free and Node-tested (engine, grad, drill, science, **research**, dataset); UI modules plug into one shell (`MODS` + `GROUPS`). app.js remains a large legacy module. | Open (refactor not attempted) |
| 15 | Performance | Info | Per-document CE costs about 0.6 s in the browser. It is dominated by the 50 257 × 256 unembedding per position, which bounds the stats and eval runtime. CPU generation is about 36 tok/s; software WebGPU is about 0.8 tok/s (see TOOLS › WEBGPU for the benchmark). | Documented |
| 16 | Statistical honesty | Info | Permutation p-values have a floor of 1/(B+1), and with N paired documents the exact floor is 2/2^N; the UI says this. Probe accuracy is reported next to the control task and majority baseline. | Documented in UI |

## Not implemented (from the candidate list)
- SAE feature splitting and transcoders.
- Edge-level ACDC.
- A Web Worker compute path (see #6).
- A separate performance dashboard. The existing WEBGPU tab benchmarks CPU vs GPU matvec and the PROFILE tab gives per-op timings.
