RISC-V inside the weights — a hand-compiled transformer CPU

Each click = one forward pass through 11 sublayers (D=, every weight computed by a compiler, nothing trained). Program ROM and data RAM live as tokens in the context; the machine state is the last token. A1 attention is instruction fetch, A2 attention is the RAM read (latest write wins). A separate JS reference interpreter checks every step.
